# 🦜👑 Spoken Like a King — 美式英语听说训练营

给孩子用的英语**听力 + 口语**练习工具，目标是说一口**地道、自然的美式英语**。
纯网页应用（PWA）：手机、平板、电脑打开就能用，可以"添加到主屏幕"像 App 一样使用，不需要安装、不需要服务器、没有广告。

吉祥物是一只戴皇冠的鹦鹉 **Kingsley**——鹦鹉最会模仿，模仿正是学口语的核心。

---

## 设计思路（为什么这样练）

| 原则 | 在工具里的体现 |
| --- | --- |
| **先听后说、听说结合** | 每日任务里听力和口语交替进行；所有句子都能 🔊 听原声、🐢 慢速听 |
| **专攻中国孩子的发音难点** | 发音实验室：th、v/w、r/l、长短元音、/æ/、词尾辅音、ng 等，用"最小对立词"（ship/sheep）训练耳朵再训练嘴巴 |
| **"美国味"来自连读和节奏** | 美式闪音 T（water→wadder）、连读、缩读（gonna/wanna/gotta）、can/can't、重音、语调专项 |
| **学真实的话，不学课本腔** | 174 个美国孩子/青少年真正在说的表达（No way! / My bad / I'm down / Fair enough…） |
| **影子跟读（Shadowing）** | 公认最有效的口语方法：模仿语速、语调、连读；可以录音"我 vs 原声"对比 |
| **在情境中开口** | 20 个情景对话（交朋友、点餐、看医生、打游戏、面试、辩论…），孩子自己选一句说，任何一句都算对 |
| **流利度 = 敢说、多说** | 自由说：30–90 秒围绕话题说，统计语速、词汇量、"um/uh"口头禅，录音保存给家长 |
| **间隔重复，不会忘** | 学过的表达按记忆曲线（1→2→4→7→15→30 天）自动安排复习 |
| **有趣才能坚持** | 每日任务闯关、星星、经验等级、金币、连续打卡火苗🔥、宝箱、70 张收藏贴纸、绕口令挑战 |
| **随年龄成长** | 6 个等级，从小学（L1）一直到高中及以上（L6：辩论、演讲、委婉表达、播客级听力） |

## 功能一览

- ⚔️ **每日任务**（约 15 分钟）：发音热身 → 新表达 → 影子跟读 → 听力 → 情景对话/自由说 → 复习，全部完成开宝箱
- 👅 **发音实验室**：16 个发音单元，听辨、对比词跟读、单词句子跟读、找重音、缩读还原
- 🦜 **影子跟读**：12 组主题句子包，每句附模仿要点（连读、语调…）
- 💬 **地道表达**：174 个表达，按 12 个类别和 6 个等级筛选，含例句
- 🎭 **情景对话**：20 个场景，角色用另一个声音说话，孩子用语音回答
- 👂 **听力训练**：11 个分级故事 + 理解题、听写、数字听辨（13 vs 30、时间、价格、年份）、真实语速、can/can't
- 🎙️ **自由说**：27 个分级话题 + 开头句提示，统计流利度并录音
- 🌀 **绕口令**：22 个，可 1.35 倍速挑战
- 🔁 **复习**：看中文说英文的间隔重复卡片
- 🤖 **AI 聊天伙伴（可选）**：和 Kingsley 用英语自由聊天（基于 Anthropic Claude），会用地道说法自然地纠正孩子，并给出 "Native tip"
- 👨‍👩‍👧 **家长中心**（乘法题验证）：学习统计、8 周打卡日历、孩子录音回放、难度/声音/语速/每日目标设置、关闭中文进入全英文沉浸模式、数据备份导入

## 怎么用

### 方式一：GitHub Pages（推荐，免费）
1. 把代码合并到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
3. 推送后 Actions 会自动测试并部署，地址类似 `https://<用户名>.github.io/spokenlikeKing/`。
4. 用手机/平板打开，浏览器菜单选"添加到主屏幕"。

> 语音识别和录音要求 **HTTPS**（GitHub Pages 自带）或 `localhost`。

### 方式二：本地运行
```bash
python3 -m http.server 8000
```
然后打开 http://localhost:8000

## 浏览器建议

| 设备 | 推荐 | 说明 |
| --- | --- | --- |
| iPhone / iPad | Safari | 支持语音识别；建议在"设置→辅助功能→朗读内容→声音→英语(美国)"下载增强版声音（如 Ava、Evan），朗读更自然 |
| 安卓 | Chrome | 语音识别需联网 |
| 电脑 | Chrome / Edge | Edge 自带很自然的 "Natural" 美式声音 |
| Firefox | 可用 | 不支持语音识别，会自动改用"录音 + 和原声对比 + 自评"模式 |

**关于语音识别的说明**：浏览器的语音识别（Chrome 使用 Google 服务，Safari 使用 Apple 服务）需要联网，在中国大陆部分网络环境下 Chrome 的识别可能不可用，Safari 通常可以。识别结果用来判断"母语者的识别系统能否听懂你"，这是很实用的可懂度指标，但它不是逐音素的专业发音打分——所以工具同时提供"我 vs 原声"录音对比，让孩子自己用耳朵比较。

## AI 聊天伙伴的设置（可选）

1. 在 [console.anthropic.com](https://console.anthropic.com) 注册并创建 API Key（按用量付费，建议在控制台设置每月消费上限）。
2. 家长中心 → AI 伙伴 → 填入 Key，选择模型：
   - Claude Opus 5.5（默认，最聪明）
   - Claude Sonnet 5.5（更快更便宜）
   - Claude Haiku 5.5（最便宜，适合大量日常聊天）
3. Key 只保存在本浏览器的 localStorage 里，只会直接发送给 Anthropic API。网络需要能访问 `api.anthropic.com`。

AI 伙伴的提示词要求它：使用自然口语、按孩子等级调整用词、每次以一个问题结尾引导孩子多说、不直接说"你错了"而是自然地用正确说法复述、不索取任何个人信息、内容适合儿童。每次对话最多 40 轮。

## 给家长的建议

1. **每天 15 分钟胜过每周一次 2 小时**，固定时间做每日任务。
2. **大量输入**：每天再看 20–30 分钟英文动画（关中文字幕），如 Bluey、Wild Kratts；大一点可以看 Avatar、纪录片。
3. 孩子说错时**不要逐一纠正**，用正确说法自然重复一遍即可，保护开口的勇气。
4. 每 3–6 个月在家长中心**升一级**；到 L4 左右可以关闭中文提示。
5. 条件允许时，每周和母语者真实交流 1–2 次，把练过的话用起来。

## 技术说明

- 纯 HTML/CSS/原生 JavaScript（ES Modules），**无需构建**，无第三方依赖（AI 伙伴使用时才从 CDN 加载 Anthropic 官方 JS SDK）。
- 朗读：Web Speech API `speechSynthesis`，自动挑选最自然的美式声音（可在家长中心更换）。
- 识别：Web Speech API `SpeechRecognition`（`en-US`），取多个候选结果与目标句做词级对齐打分（处理缩写、gonna↔going to、数字等）。
- 录音：`MediaRecorder`，录音存于 IndexedDB（只在本设备，最多保留 40 条）。
- 进度：localStorage；可在家长中心导出/导入 JSON 备份。
- 离线：Service Worker 缓存（语音识别和 AI 伙伴仍需联网）。

```
index.html              入口
css/style.css           样式（支持深色模式、手机优先）
js/app.js               路由、首页、贴纸册、练习计时
js/state.js             进度、等级、间隔重复
js/speech.js            朗读、识别、录音、录音存储
js/score.js             打分算法（有单元测试）
js/components.js        "跟我说"卡片、选择题等通用组件
js/activities/*.js      各练习模块
js/data/*.js            课程内容（发音、表达、情景、故事、跟读、绕口令、话题）
tests/                  node --test 单元测试
```

运行测试：`npm test`

### 扩充内容

所有课程内容都在 `js/data/` 下，是普通的 JS 数组，照着现有格式添加即可（例如在 `phrases.js` 里加一行 `['Phrase', '中文', 'Example.', 等级, '类别']`）。修改文件后记得把 `sw.js` 里的 `VERSION` 加一，让已安装的设备更新缓存。
